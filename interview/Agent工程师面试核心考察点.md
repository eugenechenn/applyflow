# Agent工程师面试核心考察点

> **视频来源**：《agent工程师面试 主要看这4点》
> **核心摘要**：掌握前两点属于初中级Agent工程师；若能将第三、四点讲清楚、做扎实，则说明具备丰富的生产级工程经验。

---

## 📌 岗位现状
最近面试了20多个候选人，岗位是 **Agent工程师**。目前市面上合格的人选非常稀缺。在面试过程中，我主要从以下四个维度来全面考察候选人的专业能力与工程经验。

---

## 🗂️ 核心考察维度

### 1. Agent 架构和任务拆解能力
* **核心要点**：不能仅仅停留在调用 API 的层次。
* **具体考察**：
  * 能否准确判断一个业务问题究竟是一个普通的 LLM 调用就能解决，还是需要做成 工作流（Workflow）？
  * 应该采用 **单 Agent（Single-Agent）** 还是 **多 Agent（Multi-Agent）** 架构？
  * 是否需要引入 **Planner-Executor（规划者-执行者）** 模式或 **Router（路由）** 机制？
  * 哪些关键节点需要引入 **Human-in-the-loop（人工环路/人机协同）**？
* **最佳实践趋势**：当前主流实践越来越强调**“简单加可组合”**的模式，而非盲目堆砌复杂的框架。
  * *延伸阅读推荐*：Anthropic 发布的 Agent 实践总结中明确指出——真正成功落地的系统往往不是最复杂的框架，而是清晰、可组合的工作流。
* **面试判准**：主要考察候选人能否将一个真实的业务任务，精准拆解为**状态、步骤、失败分支、工具调用和验收条件**。

### 2. 工具调用与上下文工程能力（Agent Harness）
* **核心要点**：Agent 的核心差异在于其具备**计划、调用工具、协作以及保留状态**以完成多步复杂任务的能力。
* **涉及知识点**：
  * 工具 Schema 设计、函数调用（Function Calling）、RAG（检索增强生成）、记忆机制（Memory）。
  * 权限控制、幂等性、重试与超时机制、沙箱环境（Sandbox）、上下文压缩等。
* **资深人员共识**：很多 Agent 的失败，往往不是因为大模型本身不够聪明，而是因为**工具设计得太差、上下文塞得太乱、状态不可恢复**。
* **实战面试场景**：
  * *场景题*：设计一个 Agent 来自动读取邮件、生成回复，并在必要时更新工单。
  * *考察细节*：看候选人如何设计 `tools` 参数？如何约束权限与处理异常？如何定义哪些动作可以自动化执行，哪些动作必须由人工确认？
* **能力评级**：能够清晰讲透前两点的候选人，已具备 **中级 Agent 工程师** 的能力。

### 3. 评测测试与可观测性能力 📈 *(拉开差距的关键)*
* **核心要点**：这是 Agent 工程中最容易被低估、但极其核心的能力。
* **核心组件**：
  * **Evals（评测）**：OpenAI 将 Evals 描述为“测试模型输出是否符合指定标准”的方法，并强调这是构建生产级 LLM 应用不可或缺的组成部分。
  * **Tracing（链路追踪）**：以 OpenAI Agent SDK 为例，其 Tracing 能够完整记录大模型的推理结果、`tool calls`（工具调用）、`handoffs`（转移交接）、安全护栏（Guardrails）以及自定义事件。
* **业务价值**：评测和可观测性是让 Agent 真正走向生产环境、实现可视化和监控调试的基石。

### 4. 生产可靠性与人机协同 🚀 *(判断真实落地经验)*
* **核心要点**：真正上线的生产级 Agent 面临的现实环境极其复杂，这是判断候选人是否具备真实工程经验的试金石。
* **必须考虑的工程问题**：
  * 失败恢复与重试、状态持久化、人工审核（Human-in-the-loop）、权限边界。
  * Token 成本控制、响应延迟（Latency）优化、误操作防护、日志与监控、系统降级与回滚。
* **行业框架共识**：这正是 **LangGraph** 等框架强调 *Durable execution*（持久化执行）、*Human-in-the-loop* 和 *Memory* 的原因。真实的业务 Agent 绝非一次性跑完就结束，它需要支持中途暂停、等待人工确认、恢复执行并完美保留上下文。
* **安全护栏（Guardrails）**：
  * 对用户输入进行合规性检查。
  * 对 Agent 的输出结果进行验证。
  * 对高风险工具的调用实施拦截。
  * 采用“快而便宜”的小模型作为前置过滤器（过滤不合适请求），以此优化成本与延迟。

---

## 🏆 总结
如果一个候选人能够亲手设计并交付一个**可暂停、可恢复、可审计、可回滚**的 Agent 系统，那么在目前的通用人才市场上，已经属于非常**资深**的顶级人才了。
