## 2. 第一类：业务场景题

面试官问：

- 为什么做 ApplyFlow？
- 解决了什么真实问题？
- AI 产品怎么找场景？
- 如果做 AI 招聘助手、AI 客服、AI 研报助手怎么设计？

主回答锚点：

> 真实任务不是“生成一句话”，而是岗位浏览、优先级判断、投递清单、状态回填和反馈复盘的连续流程。

优先看：

- `ApplyFlow_AI面试作品集复习手册.md`：第 2、3、7、15、19 节。
- `ApplyFlow_Agent项目简历写法与面试落地表达.md`：第 2、3、4、6、9 节。
- `AI Agent项目如何避免玩具感：简历与面试深挖清单.md`：第 1、2、3、6、7 节。
- `零经验求职 AI PM：如何将“玩具项目”包装成产品经历.md`：只看方法论，不背原文。

回答方向：

> 我不会先讲模型，而是先讲真实任务。ApplyFlow 解决的是求职者面对大量岗位时，不知道先投哪个、为什么投、投后怎么追踪的问题。AI 的价值在岗位和用户偏好之间的语义判断，系统的价值在状态管理和复盘。

## 3. 第二类：Agent 架构题

面试官问：

- Agent 和 workflow 有什么区别？
- 为什么不用普通规则？
- ReAct / Plan-and-Execute 怎么选？
- 多 Agent 和单 Agent + 多工具怎么选？
- Memory 怎么设计？

主回答锚点：

> ApplyFlow 是 Agent + workflow 的组合：确定流程用 workflow，不确定语义判断用模型。

优先看：

- `ApplyFlow_AI面试作品集复习手册.md`：第 4、7、11、14、21 节。
- `AI Agent 产品架构与面试核心业务逻辑.md`：看模块拆解。
- `AI Agent 项目面试必问的 5 个深度拷问.md`：看为什么 Agent、为什么不用 workflow。
- `破解 Agent 长上下文困境：Subagent (Boss-Worker) 架构实践.md`：只作为“复杂任务可拆角色”的背景，不主动展开。

回答方向：

> 我理解 Agent 不是会聊天，而是围绕目标推进任务。ApplyFlow 里，岗位导入、排序、投递清单和状态回填是 workflow；岗位语义理解、解释建议和风险提示才用模型。当前任务边界清楚，所以不急着上复杂多 Agent。

## 4. 第三类：系统边界题

面试官问：

- AI 生成错了怎么办？
- Prompt 注入怎么办？
- 工具调用参数乱传怎么办？
- 用户数据怎么隔离？
- 为什么不做全自动投递？
- 怎么处理隐私、安全和人工确认？

主回答锚点：

> Prompt 是软约束，Schema、权限、状态机、日志和人工确认才是硬边界。

优先看：

- `AI Agent系统治理与Coding难点面试准备.md`：第 1、3、4、5、6、7 节。
- `AI Agent 开发的终极壁垒：把“概率黑盒”变为“稳定系统”.md`：看三层防护思路。
- `阿里P8架构题：如何彻底解决 LLM 工具调用 (Tool Calling) 乱套问题？.md`：看 Tool Calling 乱套怎么兜。
- `网易AIGC内容安全策略实习：简历场景与面试落地表达.md`：看内容安全、人机边界。
- `网易AI产品运营实习面试应对手册.md`：看 AIGC 与人工内容区别、Bad Case、人工复核。

回答方向：

> 我不会让模型直接决定高风险动作。ApplyFlow 里 AI 可以给排序和解释，但状态写入、用户归属、外部投递都要经过系统校验和用户确认。网易实习里也是同样思路：生成结果要有风险分类、审核口径、Bad Case 和人工复核。

## 5. 第四类：评估指标题

面试官问：

- 你怎么评估 Agent 效果？
- eval harness 怎么搭？
- benchmark 怎么设计？
- pass@k / pass^k 是什么？
- 模型升级后怎么防止回退？
- 怎么证明不是只跑通 happy path？

主回答锚点：

> 评估不是看模型最后说了什么，而是看任务有没有完成、轨迹是否可信、结果是否进入真实系统状态。

优先看：

- `ApplyFlow_Agent评估体系面试回答.md`：全文优先。
- `ApplyFlow_AI面试作品集复习手册.md`：第 13、14、19.5、19.10、21 节。
- `AI Agent项目如何避免玩具感：简历与面试深挖清单.md`：第 5、6、7 节。
- `为什么你的 AI Agent 项目被当成“玩具”？（Toy vs Production）.md`：看 toy vs production 区别。
- `AI产品经理简历“RAG”避坑指南与面试深挖拷问.md`：只在被问 RAG 评估时看。

回答方向：

> ApplyFlow 可以按 Task / Transcript / Outcome / Grader 讲。Task 是固定用户画像和岗位池，Transcript 是排序、解释、投递清单和状态回填轨迹，Outcome 是岗位是否进入投递清单和状态是否回填，Grader 是代码脚本、人工抽检和用户反馈组合。

## 6. 第五类：数据迭代题

面试官问：

- 你有用户数据吗？
- 指标提升从哪里来？
- 用户反馈怎么转成迭代？
- Bad Case 怎么治理？
- A/B 怎么做？
- 为什么现在还不是大规模用户？

主回答锚点：

> 当前不是大规模增长数据，而是小样本同口径走查、dogfooding、朋友试用和 Evidence Log。关键是讲清数据来源、指标口径和迭代闭环。

优先看：

- `ApplyFlow_AI面试作品集复习手册.md`：第 6、13、19.5、19.6、19.8、19.10 节。
- `ApplyFlow_Agent项目简历写法与面试落地表达.md`：第 4、6、8、9 节。
- `ApplyFlow_简历修改与作品集材料方案.md`：第 3、6、9 节。
- `ApplyFlow_Agent评估体系面试回答.md`：第 6、8、9 节。

回答方向：

> 我不会把它包装成 DAU 或商业化数据。目前更准确的是 demo 到白名单内测准备阶段。投递主路径改版后，我用固定测试画像做同口径复测，投递清单候选率从 8.8% 到 16.7%，状态回填率从 33.3% 到 58.8%。这个数据是小样本复测，不是规模化增长。

## 9. 旧材料怎么处理

以后不要再从文件夹第一个文档开始读。按下面顺序：

1. 先读 `AI岗位面试题归类器：从ApplyFlow出发回答陌生题.md`，建立路由。
2. 再读本索引，知道每类题该翻哪份材料。
3. 再读 `ApplyFlow_AI面试作品集复习手册.md`，背主线。
4. 面试前只重点刷 A 级材料。
5. B 级材料用于查漏补缺。
6. C 级材料只当背景，不要给自己增加背诵负担。

## 10. 90 分钟快速复习路线

如果临近面试，只按这个来：

1. 10 分钟：背 7 类题型和 3 个锚点。
2. 20 分钟：背 ApplyFlow 30 秒、3 分钟、五个深挖问题。
3. 15 分钟：背评估体系 Task / Transcript / Outcome / Grader。
4. 15 分钟：背系统边界和 Coding 难点。
5. 15 分钟：背网易实习 30 秒、AIGC vs 人工内容、Bad Case。
6. 15 分钟：练 5 道知识盲区题，用“承认边界→接回项目→下一步”回答。
