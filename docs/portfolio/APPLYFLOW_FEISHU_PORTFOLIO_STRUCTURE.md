# ApplyFlow 飞书作品集结构

目标：做一个面试官 3-5 分钟能看懂的在线作品集页面。
建议标题：`ApplyFlow｜AI 求职执行 Agent 作品集`

## 1. 首页摘要

放在最顶部，不超过 200 字：

> ApplyFlow 是一个 AI 求职执行 Agent，围绕“先筛后投”重构求职流程，覆盖岗位导入、用户偏好建模、可解释排序、Shortlist/Compare、投递状态管理和反馈复盘。项目当前处于 Demo + 3-5 人白名单内测准备阶段，重点验证 AI 应用从 Demo 到真实试用之间的业务闭环、评测证据和数据边界。

按钮/链接：

- Demo 链接：待填
- 一页版 PDF：待填
- Evidence Log：待填
- GitHub / README：可选，技术面再给

## 2. 产品问题

用 3-4 个 bullet：

- 求职者面对大量岗位，缺少可解释的优先级判断。
- 普通求职工具偏信息展示，缺少状态管理和反馈复盘。
- 单点 AI 生成工具容易停留在 Demo，缺少评测与产品边界。
- 多用户内测前必须处理 demo 数据、真实岗位池和用户数据隔离。

## 3. 产品流程图

建议直接复制：

```text
岗位导入
→ 标准化 / 去重
→ 用户偏好建模
→ 多维匹配排序
→ Shortlist / Compare
→ 投递状态管理
→ 用户反馈 / Bad Case
→ 迭代复盘
```

如果有截图，放这些：

- Dashboard 输入偏好。
- Jobs 排序列表。
- Job detail 解释区域。
- Shortlist / Compare。
- Tracker / feedback 状态。

## 4. 核心亮点

建议分 5 个小卡片：

1. 用户偏好建模
2. 可解释岗位优先级
3. 端到端求职工作流
4. 真实岗位池排序验证
5. Demo 到内测的数据隔离与 Bad Case 机制

## 5. 指标与证据

不要写虚假的增长数据。写真实证据：

- 真实岗位池：5000+。
- 演示岗位池：覆盖多个岗位方向。
- 排序验证：多画像 TopN 检查。
- 用户隔离：demo / 真实岗位池 / 白名单用户隔离。
- 试用证据：本人 dogfooding + 朋友试用，待填。
